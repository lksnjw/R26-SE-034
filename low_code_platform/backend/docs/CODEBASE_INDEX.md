## Architectural Overview

The project is a **Go-based agentic workflow engine** that transforms natural language requests into validated, executable workflows.

### Core Pipeline
1. **Semantic Search**: Uses a Python service (`semantic_search_service`) to find relevant tools, rules, and templates.
2. **Synthesis**: LLM (Gemini/Ollama) generates workflow candidates in YAML.
3. **Validation**: Strict multi-layered check (Schema, RBAC, Governance, Policy).
4. **Execution**: The Runner executes the validated workflow steps.
