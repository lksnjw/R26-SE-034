# Configuration & Master Registries

The `configs/` directory contains system-wide configuration files and master registries.

## Registries (`configs/registries/`)

- **`all_tools_master_registry.json`**: The authoritative list of all tools available in the system across all domains.
- **`all_rules_master_registry.json`**: The authoritative list of all governance and safety rules enforced by the system.

These master registries are typically generated by aggregating files from the `dataset/` directory and are used by the engine for high-performance lookups.
