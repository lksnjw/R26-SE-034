
# ERP agent workspace frontend

The current workspace puts chat on the left and saved workflows on the right, stacking on narrow screens. Select a supported node or collection to propose edits in chat, review readable changes, then explicitly apply to a draft. Publication and execution are separate. Collection forms use Source list / Maximum items / Collected item; compiler issues remain visible rather than implying readiness.

See [current collection editing and desktop/mobile evidence](../docs/COLLECTION_NODE_CHAT_AND_DRAFT_VALIDATION_2026-10-06.md), [Firebase Hosting plan](../docs/FIREBASE_STORAGE_AND_INTEGRATION_PLAN_2026-10-06.md) and [full completion status](../docs/PROJECT_COMPLETION_STATUS_2026-10-06.md). Existing authentication remains; the browser does not receive Firestore server credentials. Latest regression: 378 Jest tests, lint/build and 15 Hosting configuration/release checks passed.
